# Security Policy

PGVortex is currently pre-release software and has no production-supported
version. Security fixes may require incompatible changes.

Please report suspected vulnerabilities using GitHub's private vulnerability
reporting for the `PGVortex/pgvortex` repository. Do not open a public issue
until the maintainers have had an opportunity to investigate and coordinate a
fix. Include affected versions or commits, reproduction steps, impact, and any
known mitigations.
